# Lab 15 - Gestion des Étudiants

Ce projet est une application Android simple développée dans le cadre du Lab 15. Elle permet de gérer des informations de base sur les étudiants (Nom, Prénom, ID).

## Fonctionnalités

L'application propose une interface utilisateur pour :
* **Saisir les informations** : Formulaire pour le nom, le prénom et l'identifiant de l'étudiant.
* **Valider** : Bouton pour valider la saisie.
* **Rechercher** : Possibilité de chercher un étudiant par son ID.
* **Supprimer** : Option pour supprimer les données.
* **Affichage des résultats** : Zone de texte pour afficher le statut ou les résultats des opérations.

## Structure du Projet

* **`MainActivity.java`** : Contient la logique principale de l'activité, y compris la gestion des Insets pour un affichage "Edge-to-Edge".
* **`activity_main.xml`** : Définit l'interface utilisateur avec des composants `EditText`, `Button` et `TextView`.

## Technologies Utilisées

* **Langage** : Java
* **Bibliothèques AndroidX** : AppCompat, Activity, Core (pour Edge-to-Edge).
* **Build System** : Gradle

## Installation

1. Clonez le dépôt.
2. Ouvrez le projet dans **Android Studio**.
3. Synchronisez le projet avec les fichiers Gradle.
4. Lancez l'application sur un émulateur ou un appareil physique.
